# المنصة الإسلامية — الإصدار V44

تضيف هذه النسخة **نظام تصميم مشترك** على مستوى صفحات الموقع، لتوحيد البانرات والخطوط ومقياس العناوين والأسطح وحالات الوضع الداكن بدل ترك كل صفحة تعمل بقواعد مستقلة.

## التشغيل المحلي

شغّل خادمًا محليًا من مجلد المشروع:

```bash
python -m http.server 8000
```

ثم افتح `http://localhost:8000/`.

على Windows يمكن تشغيل `serve.bat`، وعلى Linux/macOS يمكن تشغيل `./serve.sh`.

## بنية المشروع

- `index.html`: الصفحة الرئيسية.
- `pages/`: 94 صفحة HTML مستقلة.
- `pages-index.json`: فهرس التوجيه ويضم 87 مدخلًا.
- `assets/css/site.css`: الهيكل الأساسي للموقع والتوب بار والميجا منيو.
- `assets/css/design-system.css`: نظام التصميم الموحد للخطوط والألوان والبانرات والبطاقات والوضع الداكن.
- `assets/js/design-system.js`: تهيئة الثيم الموحدة وfallback لزر الوضع الداكن في الصفحات القديمة.
- `assets/css/home-refresh.css`: تنسيقات الصفحة الرئيسية.
- `assets/css/articles.css`: تنسيقات المقالات وصفحة المقال.
- `assets/js/components.js`: الهيدر والميجا منيو والفوتر ونافذة الحساب وشريط الهاتف.
- `assets/js/page-router.js`: التوجيه والبحث وفهرس الصفحات والحماية التجريبية للصفحات الخاصة.
- بقية ملفات JavaScript تخدم المصحف والكتب والمقالات والأذكار والأسماء والصفحات المعرفية والأدوات.
- `DESIGN-SYSTEM.md`: مرجع الألوان والخطوط والبانرات وقواعد إضافة المكونات.

## تحسينات V44 — نظام التصميم

- اعتماد Alexandria خطًا موحدًا لواجهة المستخدم في الصفحة الرئيسية وكل الصفحات الداخلية.
- توحيد تحميل حزمة الخطوط؛ Amiri وNoto Naskh Arabic محجوزان للنص القرآني وتجارب القراءة التي تحتاج إلى خط عربي قرائي.
- توحيد البانرات الداخلية على خلفية Sage خضراء هادئة مطابقة للمرجع البصري في `adhkar.html`، مع عنوان أخضر داكن ووصف واضح وحقول بحث بيضاء.
- الحفاظ على البنر الرئيسي للصفحة الرئيسية كافتتاحية مستقلة، لكنه يظل ضمن عائلة الأخضر المعتمدة.
- توحيد مقياس العناوين وقواعد الحقول والبطاقات والحواف والظلال والمسافات المشتركة.
- إصلاح تغطية الوضع الداكن على مستوى المشروع: خلفيات الصفحات والأسطح والبطاقات والحقول والنصوص والبانرات، بما في ذلك صفحات الأذكار والزكاة والمقالات والصفحات المتخصصة.
- إضافة تهيئة مبكرة للثيم من `localStorage` لتقليل ظهور الصفحة بالوضع الخطأ أثناء التحميل.
- إضافة fallback لتبديل الثيم في صفحات التحويل والصفحات القديمة التي لا تحمل `app.js`.
- الحفاظ على ثيم ورق المصحف وورق قارئ الكتب المستقل، حتى لا يؤدي تغيير ثيم الموقع إلى إفساد مساحة القراءة.

## البانرات والخطوط

- البانرات الداخلية تستخدم تدرجًا أخضر هادئًا مطابقًا لصفحة الأذكار المرجعية.
- البحث داخل البانر أبيض مع كتابة داكنة، والزر أخضر داكن.
- لا تُستخدم صور فوتوغرافية داخل البانرات؛ توضع الصور داخل محتوى الصفحة.
- تفاصيل المتغيرات وقواعد إضافة صفحات جديدة موثقة في `DESIGN-SYSTEM.md`.

## ملاحظات التكامل والمحتوى

هذه واجهات أمامية وتجارب تفاعلية أولية؛ وجود صفحة لا يعني أن كل خدمة خلفية أو قاعدة بياناتها جاهزة.

- البحث الحالي يبحث في فهرس الصفحات والموضوعات المعرّفة في الواجهة، وليس فهرسًا كاملًا لنصوص القرآن والحديث والكتب والتفاسير.
- الصور الفوتوغرافية في الموقع محملة من مصادر خارجية عبر الإنترنت؛ يلزم التحقق من شروط الاستخدام والنسب، ويفضل نقل الصور المعتمدة إلى CDN خاص بالمنصة قبل الإطلاق.
- صفحات القرآن والحديث والتفسير وغيرها تحتاج إلى ربط قواعد النصوص المعتمدة والتحقق من الطبعات والإحالات.
- مواقيت الصلاة تحتاج إلى مزود أو مكتبة حساب موثوقة وإعداد المدينة وطريقة الحساب.
- التلاوات والإذاعات تحتاج إلى مصادر بث وملفات ذات حقوق استخدام واضحة.
- بوابة الدخول الحالية معاينة واجهة وحماية جلسة تجريبية في المتصفح، وليست نظام مصادقة إنتاجيًا.
- الأسعار وواجهات الاشتراك معلوماتية؛ لا توجد بوابة دفع مفعلة في هذا النموذج.

## التحقق المنفذ في V44

- 95 ملف HTML إجمالًا: الصفحة الرئيسية و94 صفحة داخل `pages/`.
- كل ملف HTML يحمل `design-system.css` مرة واحدة و`design-system.js` مرة واحدة.
- كل صفحة تستخدم حزمة الخطوط المشتركة الموحدة.
- لا توجد معرفات HTML مكررة في الملفات التي فُحصت.
- لا توجد مراجع محلية مفقودة لملفات CSS أو JavaScript أو الصور.
- جميع ملفات JavaScript اجتازت `node --check`.
- اجتازت ملفات CSS فحص التحليل دون أخطاء.
- لم يكتمل اختبار العرض المرئي الآلي داخل Chromium في بيئة التنفيذ؛ لذا لا أصف النسخة بأنها اختُبرت بصريًا على كل المقاسات.
